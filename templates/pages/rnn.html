Why it exists: text, speech, music, stock prices and DNA are sequences. Their length varies and their order carries meaning (“dog bites man” ≠ “man bites dog”). An RNN reads a sequence one element at a time and carries a memory vector (the hidden state) from step to step, using the same weights at every step. RNNs were the state of the art for language until 2017. Their limits, slow sequential processing and fading memory, are exactly the problems the Transformer was invented to solve.

01Why order matters

The simplest way to feed a sentence to an MLP is to average its word vectors (“bag of words”). It handles any length, but it throws away the order:

$$\bar x=\frac1T\sum_{t=1}^{T}x_t$$$$\Rightarrow\ \ \bar x(\text{dog bites man})=\bar x(\text{man bites dog})$$

An RNN processes words in order, so the final hidden state depends on the sequence and not only on the set of words.

Try it: compare the two sentences on the right. The averaged vectors are identical (cosine 1.000). The RNN’s final states are different. Type your own pair to test it.

Transformer linkAttention on its own also ignores order: it is a weighted average over a set of tokens. That is why Transformers must add positional encodings. RNNs get order for free from processing step by step.

02The recurrence: one cell, reused at every step

At each time step the RNN combines the new input \(x_t\) with its previous memory \(h_{t-1}\):

$$h_t=\tanh\big(W_{hh}\,h_{t-1}+W_{xh}\,x_t+b_h\big)$$$$\hat y_t=\mathrm{softmax}(W_{hy}\,h_t+b_y)$$
\(x_t\)input at step \(t\) (e.g. a word embedding)
\(h_t\)hidden state, a fixed-size summary of everything read so far
\(W_{xh},W_{hh},W_{hy}\)weights, shared across all time steps
\(\hat y_t\)output at step \(t\) (e.g. prediction of the next word)

“Unrolling” the loop over time gives a very deep feed-forward network with one layer per time step, all layers sharing the same weights. That is the same trick as a CNN sharing weights across space, applied to time.

Try it: step through the sentence. The heat map shows the hidden state (rows = 16 hidden units, columns = time). Each new column is computed from the previous column plus the new word.

Transformer linkAn RNN squeezes the entire history into one vector \(h_t\) of fixed size. A Transformer keeps all previous token vectors and lets each new token look back at any of them directly. In practice this is the KV-cache.

03Training a character-level language model (live)

The classic RNN task: read text one character at a time and predict the next character. At every step the output is a softmax over the alphabet, and the loss is the cross-entropy summed over the sequence:

$$\mathcal L=-\frac1T\sum_{t=1}^{T}\log \hat y_t[x_{t+1}]$$

During training the model always receives the true previous character (teacher forcing). During generation it receives its own sampled output.

Try it: press Train. A real RNN (32 hidden units, about 2,000 parameters) is trained in your browser with backpropagation through time and Adam. Every few hundred steps it writes a sample. Watch it go from random characters, to the right letter frequencies, to real words from the corpus. You can replace the training text.

Transformer linkThis is the same objective as GPT, next-token cross-entropy with sampling at a temperature, only with characters instead of word pieces and an RNN instead of a Transformer. Andrej Karpathy’s famous “char-rnn” (2015) led directly to his later nanoGPT.

04Backprop through time and vanishing gradients

Training uses backpropagation through time (BPTT): unroll the network and apply ordinary backprop. To learn that a word at step \(t\) matters for a prediction at step \(T\), the gradient must flow back through every step in between:

$$\frac{\partial h_T}{\partial h_t}=\prod_{k=t+1}^{T}\frac{\partial h_k}{\partial h_{k-1}}=\prod_{k=t+1}^{T}\mathrm{diag}\big(\tanh'(\cdot)\big)\,W_{hh}$$

It is the same matrix multiplied again and again. If its largest scaling factor (spectral radius \(\rho\)) is below 1, the gradient shrinks exponentially, like \(\rho^{T-t}\): it vanishes. Above 1, it explodes.

  • Exploding: fixed by gradient clipping (rescale the gradient if its norm is too large).
  • Vanishing: much harder. The RNN effectively forgets anything more than about 10–20 steps back. This led to the LSTM.

Try it: set \(\rho\) and the sequence length. The curve is computed by multiplying real random matrices.

Transformer linkIn a Transformer, the path from token 1 to token 1000 is one attention step, not 999 multiplications. That short gradient path is a big reason why Transformers learn long-range dependencies so much better.

05LSTM and GRU: gates that protect memory

The LSTM (Long Short-Term Memory, 1997) adds a separate cell state \(c_t\) that is updated by addition and controlled by gates, small sigmoid layers outputting values between 0 (closed) and 1 (open):

$$f_t,i_t,o_t=\sigma(W[h_{t-1},x_t]+b)\qquad \tilde c_t=\tanh(W_c[h_{t-1},x_t]+b_c)$$$$c_t=f_t\odot c_{t-1}+i_t\odot\tilde c_t\qquad h_t=o_t\odot\tanh(c_t)$$
forget gate \(f\)how much of the old memory to keep
input gate \(i\)how much new information to write
output gate \(o\)how much of the memory to expose as \(h_t\)

When \(f\approx1\) and \(i\approx0\), \(c_t\approx c_{t-1}\): the memory passes through unchanged, and so does its gradient (\(\partial c_t/\partial c_{t-1}=f\approx1\)). The GRU (2014) is a simpler two-gate version.

Try it: a value is stored at step 0. Compare how much of it survives in a plain RNN and in an LSTM cell with your forget gate setting.

Transformer link\(c_t=c_{t-1}+\dots\) is an additive “highway” through time. Transformers use the same trick through depth: the residual stream \(x_{l+1}=x_l+\text{Sublayer}(x_l)\). Gating also returned in Transformers in the SwiGLU feed-forward layer of Llama.

06Seq2seq, the bottleneck, and the birth of attention

For translation, an encoder RNN reads the source sentence, and its final hidden state is handed to a decoder RNN that writes the translation (seq2seq, 2014). Problem: the whole sentence must fit in one vector. Long sentences get garbled.

Attention (Bahdanau et al., 2014) fixed this. Keep all encoder states \(h_1..h_n\). At each output step, the decoder scores every source position, turns the scores into weights with a softmax, and reads a weighted average:

$$\alpha_{tj}=\mathrm{softmax}_j\big(\text{score}(s_{t-1},h_j)\big)\qquad c_t=\sum_{j=1}^{n}\alpha_{tj}\,h_j$$

Try it: click a French output word. The bars show where the decoder “looks” in the English sentence. Note that “noir” looks at “black” even though the word order differs. (The weights here are illustrative, similar to those from a trained model.) Untick attention to see the bottleneck version: every output word gets the same single vector.

Transformer linkIn 2017, “Attention Is All You Need” asked: if attention does the real work, why keep the RNN at all? Remove the recurrence, let every token attend to every other token (self-attention), add positions, and stack the layers. That is the Transformer.

Try it: drag the sequence length. On a GPU, parallel work is almost free and sequential steps are what cost time. That is why Transformers train much faster, even though they do more total work.

RNNs are coming backThe \(O(n^2)\) cost of attention for very long inputs has revived recurrent ideas: state-space models such as Mamba and RWKV train in parallel like Transformers but generate like RNNs with constant memory. Several recent LLMs mix attention layers with such recurrent layers.

Teach it in one sentence: an RNN reads a sequence step by step, updating a hidden memory with the same weights each time, and is trained to predict the next token by backpropagation through time. Its fading memory and sequential speed limit led to gated LSTMs and then to attention, and so to the Transformer.
