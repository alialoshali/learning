01AI, machine learning, deep learning, generative AI: what is the difference?

These four words are often used as if they meant the same thing. They are actually nested: each one is a special case of the one around it. Hover over (or tap) the rings on the right.

Key definitions
Artificial intelligence (AI)
Any technique that makes a computer do something we would call “intelligent” if a person did it: planning, recognising, translating, deciding. Includes hand-written rules (e.g. a chess program searching moves).
Machine learning (ML)
AI that learns from data: the program’s behaviour comes from numbers fitted to examples, not from rules a person wrote.
Deep learning (DL)
Machine learning with neural networks of many layers. Each layer learns features from the previous one. Behind almost all modern vision, speech and language AI.
Generative AI
Deep-learning models that create new content (text, images, audio, code) by learning the probability distribution of their training data. Large language models (LLMs) are generative AI for text.
Model
The learned function: input → output. Concretely, a formula plus its fitted numbers (parameters).
Transformer linkChatGPT and Claude sit in the innermost ring: a Transformer (deep learning) trained on text (machine learning) to generate answers (generative AI).

Nested fields of AI

How to read this diagramEach ring is a field; a ring inside another is a subset of it. So every deep-learning model is a machine-learning model, but a decision tree is machine learning without being deep learning, and a rule-based chess engine is AI without being machine learning. The years show roughly when each field became prominent.

02See a machine learn, right now

“Learning” in machine learning is surprisingly concrete. Here is the whole idea in one small experiment: a model must separate blue points from orange points with a straight line.

  1. Predict. With its current numbers, the model guesses a colour for every point. The shading on the right shows the guess for every location.
  2. Measure the error. One number, the loss, says how wrong the guesses are (lower = better).
  3. Adjust. Calculus tells us in which direction to nudge each number to reduce the loss. This is gradient descent.
  4. Repeat hundreds of times. The line rotates into place and the loss curve falls.

Try it: press Learn. Then click on the plot to add your own points (left-click blue, right-click or shift-click orange) and watch the model adapt. Put an orange point deep among the blue ones: a straight line can no longer separate them perfectly, which is why we later need neural networks.

Terms used here
Training data
The examples the model learns from (the dots, each with its true colour).
Parameters
The adjustable numbers of a model, here 3: two weights \(w_1,w_2\) and a bias \(b\).
Loss
A single number measuring how wrong the model is on the training data.
Decision boundary
The line where the model switches its answer from one class to the other.

Logistic regression learning live

How to read this graph
  • Top plot: each dot is one training example placed by its two features \(x_1\) (horizontal) and \(x_2\) (vertical); its colour is the true answer. The background shading is the model’s prediction for every location (stronger colour = more confident). The black line is the decision boundary.
  • Bottom plot: the loss after each training step (horizontal = step number, vertical = loss). A falling curve means the model is learning. 0.69 = random guessing.
  • The text line shows the current parameters and the accuracy (share of dots on the correct side).

04The recipe behind every model

From the simplest line to GPT, every model in this course is built with the same five ingredients. Click each box in the diagram to see what it means, its formula, and where it is taught.

$$\theta^\star=\arg\min_{\theta}\ \frac1N\sum_{i=1}^{N}\ell\big(f_\theta(x_i),\,y_i\big)$$Read: “find the parameters \(\theta\) that make the average error \(\ell\) between the model’s predictions \(f_\theta(x_i)\) and the true answers \(y_i\) as small as possible.” This one line summarises machine learning.
\(x_i,\ y_i\)the \(i\)-th example: its input and its correct answer
\(f_\theta\)the model, a function with adjustable parameters \(\theta\) (theta)
\(\ell\)the loss for one example: how far the prediction is from the answer
\(N\)the number of training examples
\(\arg\min\)“the value that gives the minimum”

The learning loop (click a box)

How to read this diagramArrows show the order of work. The top row is the forward pass: data goes in, the model predicts. The loss compares the prediction with the truth, and the orange feedback arrow is training: the optimizer changes the model’s parameters to reduce the loss. After training, only the top row is used (that is called inference).

06A short history of AI

Modern AI is the result of 80 years of ideas, failures and comebacks. Click the dots on the timeline. Notice how often an idea taught in this course appeared decades before it became useful. Neural networks only took off when data (the internet) and compute (GPUs) became large enough.

Periods of disappointment and reduced funding are called AI winters (shaded). Each ended when a new idea, more data, or faster hardware made the old promises work.

Pattern to noticeThe neuron (1943) → the trainable perceptron (1958) → backpropagation for many layers (1986) → deep CNNs on GPUs (2012) → attention and the Transformer (2017) → large language models (2018–today). This course follows the same path.

07Inside a Transformer: where this course is heading

A Transformer is the architecture inside ChatGPT, Claude, Gemini and Llama. It looks complicated, but it is built almost entirely from pieces you will learn one by one. Hover over (or tap) a block in the diagram to see which lesson teaches it.

  1. Text is cut into tokens and each token becomes a vector (embedding).
  2. Attention lets every token gather information from the others.
  3. A small neural network (MLP) processes each token.
  4. Steps 2–3 repeat in dozens of identical blocks, held stable by residual connections and normalisation.
  5. A final softmax turns scores into the probability of every possible next token.

Training uses the same loop as section 04: predict the next token, measure the error with cross-entropy, adjust billions of parameters by gradient descent.

A Transformer, block by block

How to read this diagramData flows from the bottom (input text) to the top (the predicted next word). The dashed frame is one Transformer block; real models stack 12–100+ of them. The curved arrows on the right are residual connections: each block adds its result to its input instead of replacing it.
