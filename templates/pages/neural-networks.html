Why it exists: linear and logistic regression can only draw straight boundaries, and a person has to design their input features. A neural network stacks simple units (neurons) in layers with a non-linear function between them, so it can learn its own features and fit almost any shape. A deep neural network has many such layers, and each layer builds on the previous one. Trained with backpropagation and gradient descent, this recipe powers image recognition, speech and every Transformer. Every figure has a 👁 How to read this graph guide.

01Why we need more than a linear model

Logistic regression computes \(\hat p=\sigma(w_1x_1+w_2x_2+b)\). Its decision boundary \(w_1x_1+w_2x_2+b=0\) is always a straight line. Many real problems are not separable by a line. The classic example is XOR: class 1 when exactly one of the inputs is positive.

\(x_1, x_2\)the two input features of one example (its horizontal and vertical position)
\(w_1, w_2\)weights: how strongly each input pushes towards class 1
\(b\)bias: shifts the line without turning it
\(\sigma\)sigmoid, squashes the score into a probability between 0 and 1
\(\hat p\)predicted probability of class 1

Try it with the three buttons on the right:

  1. Logistic regression (no hidden layer): it cannot do better than about 50–75% accuracy, because one straight line can never separate XOR.
  2. + hand-made feature \(x_1x_2\): a person adds a clever extra input. Now a straight line in 3-D works, and the model succeeds. This is the old way: people engineer features by hand.
  3. ANN with a hidden layer: no hand-made feature. A hidden layer of 4 neurons learns its own features \(h=\phi(W_1x+b_1)\), and a linear output neuron on top of \(h\) makes the decision. It reaches ~100% by itself.

How exactly does a hidden layer do that? The worked example just below solves XOR with only 2 hidden neurons whose weights you can check by hand.

Key terms
Linear model
A model whose score is a weighted sum w₁x₁ + w₂x₂ + b. Its decision boundary is always a straight line (a flat plane in more dimensions).
Linearly separable
Data whose classes can be split perfectly by one straight line. XOR is not.

Inventing new input features by hand (like x₁·x₂) so a simple model can solve the problem.

Transformer linkNobody hand-designs features for language. Every layer of a Transformer learns new features of the tokens from the previous layer’s features, which is where the “deep” in deep learning comes from.

Worked example: an ANN that solves XOR, by hand

Use the 4 classic XOR inputs, where \(x_1, x_2\) are 0 or 1 and the answer is 1 when exactly one input is 1. The network has 2 inputs → 2 hidden neurons → 1 output. To keep it readable each neuron uses the step activation: output 1 if its score is above 0, otherwise 0.

$$h_1=\mathrm{step}(1\cdot x_1+1\cdot x_2-0.5)$$$$h_2=\mathrm{step}(1\cdot x_1+1\cdot x_2-1.5)$$$$\hat y=\mathrm{step}(1\cdot h_1-2\cdot h_2-0.5)$$\(x_1,x_2\) = inputs (0 or 1) · \(h_1,h_2\) = outputs of the two hidden neurons · \(\hat y\) = the network’s answer · the numbers 1, 1, −2 are weights and −0.5, −1.5, −0.5 are biases · \(\mathrm{step}(z)=1\) if \(z>0\), else 0.

What each neuron learned to detect:

  • \(h_1\) fires when \(x_1+x_2>0.5\), i.e. when at least one input is 1. It is an OR detector.
  • \(h_2\) fires when \(x_1+x_2>1.5\), i.e. when both inputs are 1. It is an AND detector.
  • The output fires when \(h_1=1\) and \(h_2=0\): “at least one, but not both”. That is exactly XOR.

The key idea (plot ② in the figure): the hidden layer moves the points to new coordinates \((h_1, h_2)\). In the original space no line separates the classes. In the hidden space the two blue points (0,1) and (1,0) both land on the same spot (1, 0), and now one straight line separates blue from orange. The output neuron is just a linear classifier, but working on better features.

In a trained network nobody chooses these weights: gradient descent finds them (or a different but equivalent set), and the step is replaced by a smooth function such as tanh or ReLU so that gradients exist. Click the rows of the truth table to follow each input through the network.

02From one neuron to a deep network: a live race

The question: if we want a network to learn a complicated shape, is it better to add more neurons in one layer (wider) or more layers (deeper)? And what can a network with no hidden layer do at all?

The experiment: four networks learn the same data at the same time, with the same loss (cross-entropy), the same activation (tanh), the same training rule (plain gradient descent, learning rate 0.5) and the same number of steps. The only difference is the architecture, shown in the small diagram in each card.

Networks ③ and ④ are the fair duel: they have about the same number of parameters (161 vs 177), but ③ spends them on one wide layer of 40 neurons, ④ on three narrow layers of 8.

Training starts when the race scrolls into view. Watch for about 20 seconds, then switch the dataset.

Conclusions
  1. No hidden layer = one straight line. ① can never learn XOR, the circle or the spiral, however long it trains.
  2. A hidden layer lets the boundary bend, but only as much as its neurons allow: 2 neurons give 2 straight cuts, enough for a band (XOR, roughly) but not a ring or a spiral.
  3. Easy shapes: width and depth tie. On XOR and the circle, ③ and ④ are equally good: one wide layer is enough.
  4. Hard shapes: depth wins. With the same parameter budget, the deep network learns the spiral about twice as fast and more steadily, using fewer neurons (24 vs 40). Each layer builds on the previous one: layer 1 makes straight cuts, layer 2 combines them into curved regions, layer 3 combines those into spiral arms. The wide network must build every curve from straight cuts in a single step.
This is why modern models are deep: GPT-3 has 96 layers rather than one enormous layer. Section 06 shows the mathematical reason.

03The neuron and activation functions

An artificial neuron is logistic regression with a choice of output function \(\phi\), the activation:

$$a=\phi\Big(\sum_j w_jx_j+b\Big)=\phi(w^\top x+b)$$\(x_j\) = the \(j\)-th input · \(w_j\) = its weight · \(\sum_j\) = add over all inputs · \(b\) = bias · \(w^\top x\) = the same weighted sum written as a dot product of the weight vector and input vector · \(\phi\) = activation function · \(a\) = the neuron’s output (its activation).

A layer is many neurons side by side, written as one matrix product: \(h=\phi(Wx+b)\) with \(W\in\mathbb R^{m\times n}\).

Why must \(\phi\) be non-linear? Without it, two layers collapse into one: \(W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)\), still a single linear map. The non-linearity is what lets depth add power.

ActivationFormulaNotes
sigmoid\(1/(1+e^{-z})\)output in (0,1); gradient ≤ 0.25 → vanishing gradients in deep nets
tanh\(\tanh z\)zero-centred; still saturates
ReLU\(\max(0,z)\)simple, gradient 1 for \(z>0\); default since ~2012
GELU\(z\,\Phi(z)\)smooth ReLU; used in BERT and GPT

04Universal approximation: bumps from ReLUs

How can stacking such simple pieces fit any shape? Look at one hidden layer of ReLUs feeding one output:

$$\hat y(x)=\sum_{j=1}^{H}v_j\,\mathrm{ReLU}(w_jx+b_j)+c$$\(x\) = input · \(H\) = number of hidden neurons · \(w_j, b_j\) = weight and bias of hidden neuron \(j\) (they set where its hinge bends: at \(x=-b_j/w_j\)) · \(\mathrm{ReLU}(z)=\max(0,z)\) · \(v_j\) = output weight of neuron \(j\) (how steep its ramp is in the sum) · \(c\) = output bias · \(\hat y\) = network output.

Each ReLU is a “hinge”: flat, then a straight ramp starting at \(x=-b_j/w_j\). Adding hinges with different start points and weights gives a piecewise-linear curve. With enough hinges it can follow any continuous curve as closely as we like. This is the universal approximation theorem.

Try it: raise the number of hidden units \(H\). Thin lines are the individual weighted hinges \(v_j\,\mathrm{ReLU}(\cdot)\); the thick line is their sum. (Here the hinge positions are spread evenly and only \(v\) is fitted, by least squares. A trained network also learns where to put the hinges.)

Width vs. depthOne very wide layer can approximate anything in theory, but deep networks do it with far fewer units, because each layer can reuse and combine the features of the previous one: edges → shapes → objects, or characters → words → meaning.

06Neural network vs. deep neural network: what exactly is the difference?

“Artificial neural network” (ANN) is the general name for any model built from artificial neurons. In practice people distinguish three sizes:

Single neuronShallow NN (“ANN”)Deep NN

Symbols in the formula row: \(x\) = input vector; \(w, b\) = weights and bias of a single neuron; \(\sigma\) = sigmoid; \(W_1, W_2, W_3\) = the weight matrices of layers 1, 2, 3 (one row of weights per neuron); \(\phi\) = the activation function (ReLU, tanh…) applied after each hidden layer. Biases are left out of the shallow and deep formulas to keep them short.

Deep learning simply means training deep networks. Depth matters for two reasons:

  1. Hierarchy. Each layer combines the features of the layer below: pixels → edges → shapes → objects; letters → words → phrases → meaning. Every level reuses the previous one instead of starting from scratch.
  2. Efficiency. Some functions need exponentially many neurons in one wide layer but only a few in several narrow layers. The figure on the right proves this with a simple example, explained step by step below.

The folding example, step by step

Step 1: one layer of 2 ReLU neurons makes a “tent”. Take an input \(x\) between 0 and 1 and compute

$$t(x)=2\,\mathrm{ReLU}(x)\;-\;4\,\mathrm{ReLU}(x-0.5)$$\(x\) = input between 0 and 1 · \(\mathrm{ReLU}(z)=\max(0,z)\) · neuron 1 computes \(\mathrm{ReLU}(x)\) (weight 1, bias 0) · neuron 2 computes \(\mathrm{ReLU}(x-0.5)\) (weight 1, bias −0.5) · the output adds them with weights 2 and −4 · \(t(x)\) = the layer’s output.

For \(x\) from 0 to 0.5 only neuron 1 is active, so \(t\) rises from 0 to 1. After 0.5 neuron 2 switches on and pulls it back down to 0 at \(x=1\). The output is again between 0 and 1: the layer has folded the interval [0, 1] in half, like folding a strip of paper.

Step 2: stack the same layer. Feed the output into the same layer again: \(f_d(x)=t(t(\cdots t(x)))\), \(d\) times. Each fold doubles the number of zig-zags, so after \(d\) layers the curve has \(2^d\) straight pieces. Use the slider and look at the small curves “after layer 1, 2, 3…”: each row is the previous one folded again.

Step 3: count the neurons. The deep network uses \(2d\) hidden neurons (2 per layer). A network with one hidden layer can only add up hinges (section 04): it needs roughly one ReLU per corner of the curve, about \(2^d\) neurons. For \(d=10\): 20 neurons deep versus about 1,024 shallow; for \(d=20\): 40 versus about a million.

Why this matters: real-world patterns are built from repeated parts (edges → shapes → objects; letters → words → sentences). Depth lets a network reuse the same computation again and again, just as the folding reuses one small layer.

Why didn’t we always go deep?Until about 2010, deep networks were very hard to train: gradients vanished (section 11), computers were slow, and datasets were small. ReLU, better initialisation, GPUs, big datasets and residual connections changed that, and the deep-learning era began (AlexNet, 2012).

07Loss and gradient descent for a neural network

Training needs a single number for “how wrong”, the loss, and a rule to reduce it, gradient descent:

$$w\;\leftarrow\;w-\eta\,\frac{\partial \mathcal L}{\partial w}$$The derivative \(\partial\mathcal L/\partial w\) is the slope of the loss; it points uphill, so we step the other way. \(\eta\) (eta) is the learning rate.

For linear regression the loss was a perfect bowl with one bottom. For neural networks it is non-convex: it has several valleys. Where you end up depends on where you start and how big your steps are.

Try it on a 1-weight example with two valleys:

  • η = 0.1, start = 2 → it settles in the shallow right valley (a local minimum).
  • Start = −2 → it finds the deeper left valley (the global minimum).
  • Tiny η → very slow; η ≈ 1.1 → it overshoots and bounces or flies off.

Real networks have millions of weights, but the loss landscape has many good valleys, and the noise from mini-batches plus good initialisation usually finds one of them.

08Backpropagation: the chain rule, backwards

To train with gradient descent we need \(\partial L/\partial w\) for every weight. Backpropagation computes them all in one backward sweep using the chain rule. Take the smallest example, one neuron with squared loss:

$$z=wx+b,\qquad a=\sigma(z),\qquad L=(a-y)^2$$\(x\) = input · \(w, b\) = weight and bias · \(z\) = weighted sum · \(\sigma\) = sigmoid · \(a\) = neuron output (prediction) · \(y\) = the correct answer · \(L\) = loss (squared error).
$$\frac{\partial L}{\partial w}=\underbrace{\frac{\partial L}{\partial a}}_{2(a-y)}\cdot\underbrace{\frac{\partial a}{\partial z}}_{\sigma(z)(1-\sigma(z))}\cdot\underbrace{\frac{\partial z}{\partial w}}_{x}$$\(\partial L/\partial w\) (“partial derivative of L with respect to w”) = how much the loss changes when w is increased a tiny bit, all else fixed · each factor is a local derivative, written under its brace · \(\sigma(z)(1-\sigma(z))\) is the slope of the sigmoid.
  1. Forward (blue, left → right): compute and store every intermediate value.
  2. Backward (orange, right → left): start with \(\partial L/\partial L=1\). At each node, multiply the incoming gradient by the node’s local derivative and pass it on.

Each node only needs its own local derivative, so this works for any graph of operations, however deep. The cost of the backward pass is about 2× the forward pass, regardless of the number of parameters.

Try it: move the sliders. The numbers under each node update. The last line compares the backprop gradient with a numerical estimate \(\frac{L(w+\epsilon)-L(w-\epsilon)}{2\epsilon}\). They agree: this “gradient check” is how people debug backprop code.

Key terms
Chain rule
The derivative of a composition is the product of the derivatives of its parts: d/dx f(g(x)) = f′(g(x))·g′(x).
Computational graph

Local derivative
The derivative of one box’s output with respect to its own input (e.g. σ′(z)).
Backward pass
Computing all gradients from the output back to the inputs.

Comparing backprop’s gradient with a numerical estimate to catch bugs.

10Optimizers: SGD, momentum, Adam

Plain gradient descent struggles in long, narrow valleys: it zig-zags across the steep walls and crawls along the flat floor. Two fixes, combined in Adam:

  • Momentum: keep a running average of gradients (velocity). Zig-zags cancel out, and consistent directions build up speed.
  • Adaptive steps: divide each parameter’s step by a running average of its squared gradient. Steep directions get small steps, flat directions get large ones.
$$m\leftarrow\beta_1m+(1-\beta_1)g\qquad v\leftarrow\beta_2v+(1-\beta_2)g^2$$$$\theta\leftarrow\theta-\eta\,\frac{\hat m}{\sqrt{\hat v}+\epsilon}$$\(\theta\) = one parameter · \(g\) = its current gradient · \(m\) = running average of gradients (momentum) · \(v\) = running average of squared gradients · \(\beta_1, \beta_2\) = how much of the old averages to keep · \(\hat m,\hat v\) = bias-corrected averages (they start at 0, so early values are scaled up) · \(\eta\) = learning rate · \(\epsilon\) = tiny number to avoid dividing by 0. Typical: \(\beta_1=0.9,\ \beta_2=0.999\).

Try it: press Race. All three start at the same point on a banana-shaped valley (the Rosenbrock function); the minimum is at ★. Change the learning rate and race again.

Real training uses mini-batches: each gradient is computed on a random batch of examples, not the whole dataset. That makes it noisy (stochastic gradient descent, SGD), but much cheaper and, surprisingly, it often finds solutions that generalise better.

Key terms
SGD
Stochastic gradient descent: gradient descent on random mini-batches.
Mini-batch
A small random subset of the training data used for one update.
Momentum
A running average of past gradients, like a ball rolling with inertia.
Adam
Momentum plus a per-parameter step size based on recent gradient sizes.
β₁, β₂
How much of the old running averages to keep each step (0.9 and 0.999).
Learning-rate schedule
Changing η during training: warm-up, then gradual decay.
Transformer linkVirtually every LLM is trained with AdamW (Adam + decoupled weight decay), mini-batches of millions of tokens, and a learning-rate schedule: linear warm-up, then cosine decay.

11Going deep: vanishing gradients and residual connections

Backprop multiplies one local derivative per layer. In a deep network the gradient reaching layer 1 is a product of many factors:

$$\frac{\partial L}{\partial h_1}=\frac{\partial L}{\partial h_n}\prod_{l=1}^{n-1}\frac{\partial h_{l+1}}{\partial h_l}$$\(h_l\) = the output vector of layer \(l\) · \(n\) = number of layers · \(\partial L/\partial h_1\) = the gradient arriving at the first layer · \(\prod\) = multiply all the factors together · each factor \(\partial h_{l+1}/\partial h_l\) = how much layer \(l+1\) changes when layer \(l\) changes (weights × activation slope).

If those factors are typically smaller than 1 (sigmoid’s derivative is at most 0.25), the gradient vanishes exponentially and early layers stop learning. If they are larger than 1, it explodes. Fixes developed between 2010 and 2016 made deep learning work:

  • ReLU activations (derivative 1 where active).
  • Careful initialisation (He/Xavier: weight variance \(\approx 2/n_{\text{in}}\) or \(1/n_{\text{in}}\)) so signals keep their size.
  • Normalisation layers (BatchNorm, LayerNorm) that rescale activations at every layer.
  • Residual connections (ResNet, 2015): \(h_{l+1}=h_l+f(h_l)\). Then \(\frac{\partial h_{l+1}}{\partial h_l}=I+f'\), and the identity gives the gradient a direct “highway” back to layer 1.

Try it: a real random network is built and back-propagated. With sigmoid and 30 layers, the gradient at layer 1 is about 10⁻¹⁵ of the last layer’s. Tick residual, or switch to ReLU with He init, and the bars stay level.

Key terms
Vanishing gradient
Gradients shrink layer after layer, so the early layers stop learning.
Exploding gradient
Gradients grow layer after layer, so training becomes unstable.
He / Xavier initialisation
Choosing the size of the random starting weights so that signals keep the same size from layer to layer.
Normalisation (LayerNorm)
Rescaling activations at every layer to a standard size.
Residual (skip) connection
h + f(h): the layer adds a correction to its input, giving gradients a shortcut.
Transformer linkEvery Transformer sub-layer is wrapped as \(x+\text{Sublayer}(\text{LayerNorm}(x))\): a residual connection plus normalisation. These are why 100-layer Transformers can be trained at all.

Teach it in one sentence: a neural network is a stack of linear layers with non-linear activations between them. It is trained end to end by backpropagation (the chain rule applied backwards) and an optimizer like Adam, and with residual connections and normalisation it can be made very deep.
