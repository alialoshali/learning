Why it exists: labels are expensive. Someone has to tag every photo or mark every email. Raw data is nearly free: billions of images, all of Wikipedia, every sensor reading. Unsupervised learning finds structure in data without any answers: groups, main directions, which points are typical and which are strange. Its central object, a model of the data distribution \(p(x)\), is exactly what a language model learns.

01Learning without answers

In supervised learning each example came with a label \(y\). Now we only have inputs:

$$\mathcal D=\{x_1,x_2,\dots,x_N\}\qquad\text{(no }y\text{)}$$

Without a correct answer there is no “error” in the usual sense. So what do we learn? We ask questions about the data itself:

  • Which points belong together? → clustering
  • Which few directions explain most of the variation? → dimensionality reduction (PCA)
  • How likely is a point? Which ones are strange? → density estimation, anomaly detection
  • Can we produce new, realistic examples? → generative models

Try it: on the right is a dataset of customers (time on the site vs. money spent). Nobody told us there are customer types. Press Find groups and watch structure appear from unlabelled points.

Why it is neededThe amount of labelled data is tiny compared with unlabelled data. ImageNet has about 1.2 million labelled images; the web has billions of unlabelled ones. Methods that learn from unlabelled data can use far more of the information that exists.

02Four jobs on the same data

The same unlabelled point cloud can be asked four different questions. Click through them on the right:

ClusteringSplit the points into \(K\) groups so that points within a group are close. Output: a group id per point. Lesson →
Dimensionality reductionFind a lower-dimensional description, e.g. the line that keeps most of the spread. Output: new coordinates. Lesson →
Density estimationLearn \(p(x)\): how likely each region of space is. Output: a probability density.
Anomaly detectionFlag points where \(p(x)\) is very low: fraud, faults, intrusions. Output: a strangeness score.

Each has its own “loss”. Clustering minimises the distance to group centres, PCA minimises the reconstruction error, and density estimation maximises the likelihood of the data:

$$\max_\theta\ \sum_{i=1}^N\log p_\theta(x_i)$$Maximum likelihood: choose the model under which the observed data is most probable. This is the same principle behind cross-entropy.
Transformer linkA language model is a density estimator for text. Its training objective is exactly “maximise \(\sum\log p_\theta(\text{text})\)”. The only difference from this plot is that \(x\) is a sequence of tokens instead of a 2-D point.

03Density estimation: histogram → kernel density

The simplest density estimate is a histogram: count the points in each bin. Its shape depends a lot on the bin width, and it is jagged. A kernel density estimate (KDE) places a small bell curve on every data point and adds them up:

$$\hat p(x)=\frac1N\sum_{i=1}^N \frac{1}{h\sqrt{2\pi}}\exp\!\Big(-\frac{(x-x_i)^2}{2h^2}\Big)$$
\(x_i\)the \(N\) observed data points (ticks under the plot)
\(h\)bandwidth: width of each bump, a hyper-parameter
\(\hat p(x)\)estimated density; its total area is 1

The same over/under-fitting story returns. A tiny \(h\) puts a spike on every training point (memorising). A huge \(h\) blurs everything into one hump. To choose \(h\) without labels, we score the log-likelihood of held-out points: a good density gives new data high probability. Find the \(h\) that maximises it.

Transformer linkEvaluating an LLM by perplexity on held-out text is this exact test: how much probability does the model give to text it has never seen? Lower perplexity means higher held-out likelihood.

04Generative models: sample new data from p(x)

Once we have a density \(\hat p(x)\), we can draw new samples from it, producing data that looks like the training data but is new. For a KDE this is easy:

  1. pick a random training point \(x_i\);
  2. add Gaussian noise with standard deviation \(h\).

Press Generate to create new points (orange) from the learned density of the original points (blue). Small \(h\) → near-copies of training points (memorisation). Large \(h\) → blurry samples that lose the structure.

High-dimensional data such as images or sentences cannot be handled with a simple KDE, because the space is far too big. Modern generative models (VAEs, diffusion models, GPT) are neural networks that represent \(p(x)\) in a clever, compact way. Language models use the chain rule of probability to break one huge distribution into a product of next-token predictions:

$$p(x_1,\dots,x_T)=\prod_{t=1}^{T}p\big(x_t\mid x_1,\dots,x_{t-1}\big)$$Each factor is a classifier over the vocabulary. Sampling = predict a distribution, draw a token, append it, repeat.
Transformer link“Generating text” with ChatGPT is sampling from a learned density, one token at a time. The temperature setting plays the role of \(h\): low = conservative, near-copies of common phrases; high = more varied, more random.

05Representations: embeddings learned without labels

A powerful use of unlabelled data is learning representations: vectors in which similar things are close together. The classic example is word embeddings (word2vec, 2013). They were learned only from which words appear near each other in raw text (“you shall know a word by the company it keeps”).

Two measures of similarity are used everywhere:

$$\cos(a,b)=\frac{a\cdot b}{\lVert a\rVert\,\lVert b\rVert}\in[-1,1]\qquad d(a,b)=\lVert a-b\rVert$$

Directions in the space can carry meaning. The famous example: \(\overrightarrow{\text{king}}-\overrightarrow{\text{man}}+\overrightarrow{\text{woman}}\approx\overrightarrow{\text{queen}}\). The “male → female” offset is roughly the same arrow everywhere.

Try it: pick A − B + C on the right. The arrow B→A is added at C, and the nearest word to the result is shown. (This is a hand-made 2-D toy; real embeddings have hundreds of dimensions. Cosines are measured from the centre of the cloud.)

Transformer linkEvery Transformer begins with an embedding table, and its internal vectors keep this geometric meaning. Attention scores are dot products between such vectors. RAG (retrieval) systems find relevant documents by the cosine similarity of their embeddings.

06Autoencoders: learn by compressing

An autoencoder is a neural network trained to copy its input to its output through a narrow bottleneck:

$$z=\text{enc}_\phi(x)\in\mathbb R^{k},\qquad \hat x=\text{dec}_\psi(z),\qquad \mathcal L=\lVert x-\hat x\rVert^2$$

The label is the input itself, so no human labels are needed. Because \(z\) has only \(k\) numbers, the network is forced to keep the most important information and throw away the rest. The code \(z\) becomes a compact representation.

  • A linear autoencoder with MSE loss learns the same subspace as PCA.
  • Non-linear (deep) autoencoders find curved structure.
  • Variational autoencoders (VAEs) make \(z\) a probability distribution, so we can sample new data.

Try it: shrink the bottleneck \(k\). The signal on the right is rebuilt from only \(k\) numbers (here using a fixed set of smooth basis waves, which shows the effect of a bottleneck). Watch the reconstruction error grow as \(k\) falls.

Transformer linkThe “predict your own input” idea leads straight to self-supervised learning. BERT is trained to reconstruct masked words, MAE to reconstruct masked image patches, and Stable Diffusion runs inside an autoencoder’s compressed space.

Teach it in one sentence: unsupervised learning finds structure in data that has no labels (groups, directions, densities, representations), and learning \(p(x)\) itself is the idea that grows into today’s generative models.

The line between unsupervised and self-supervised learning is thin: self-supervised methods make up labels from the data (e.g. the next word) and then use ordinary supervised machinery.
