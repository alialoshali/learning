01Writing rules vs. learning rules

A classic program is a set of rules written by a person. To decide whether a fruit is ripe, you might write: if colour > 5 then "ripe". That works for easy problems. But who could write the rules for “is there a cat in this photo?” or “what word comes next?”

Machine learning turns the process around. We give the computer examples with answers, and it searches for the rule that makes the fewest mistakes on them.

Try it on the right. Each dot is a fruit, placed by its colour score (0 = green, 10 = red). The top row holds fruits that were really ripe, the bottom row unripe ones. Drag the slider to choose a rule yourself. Then press Let the machine learn. The computer tries every threshold, counts the mistakes for each one (the lower curve) and keeps the best. Learning is a search for the parameter value that makes the error smallest.

Transformer linkGPT-4 learns in the same way. It has billions of thresholds and weights instead of one, and it is scored on predicting the next word instead of on ripe fruit. The idea stays the same: adjust the parameters so the error on examples goes down.

02The universal recipe: data, model, loss, optimizer

Every algorithm in this course, from linear regression up to the Transformer, is built from the same four ingredients. Learn these four words and every new model will look familiar:

1 · DataExamples \((x_i, y_i)\). Here \(x\) is the input (features) and \(y\) is the answer we want, if we have one.
2 · ModelA function \(f_\theta(x)\) with adjustable parameters \(\theta\) (weights). It turns an input into a prediction \(\hat y\).
3 · LossA single number \(\mathcal L(\theta)\) that measures how wrong the predictions are. Small is good.
4 · OptimizerA procedure that changes \(\theta\) so the loss goes down, usually gradient descent.
$$\theta^\star=\arg\min_\theta\;\underbrace{\frac1N\sum_{i=1}^{N}\ell\big(f_\theta(x_i),\,y_i\big)}_{\text{average loss on the training data}}$$Training = find the parameters \(\theta^\star\) that make the average loss as small as possible. This one line describes nearly all of machine learning.
$$\theta\;\leftarrow\;\theta-\eta\,\nabla_\theta\mathcal L(\theta)$$Gradient descent: take a small step of size \(\eta\) (the learning rate) downhill. The gradient \(\nabla\mathcal L\) points uphill, so we step the other way.

03Everything becomes a vector of numbers

A model can only compute with numbers. So before learning starts, every input is turned into a list of numbers called a feature vector \(x\in\mathbb R^d\). Here \(d\) is the number of features.

  • Table row (an apartment): \(x = [\text{size}, \text{age}, \text{rooms}]\), so \(d=3\).
  • Image: each pixel's brightness is one number. A 10×10 image gives \(d=100\). A phone photo has millions.
  • Text: split the text into tokens (words or word pieces), give each token an id, then look up a learned vector for that id. This vector is called an embedding.

Try it. In Image mode, draw on the grid and watch the 100-number vector change. In Text mode, type a sentence and watch it become token ids and then vectors.

Why it mattersOnce data is a vector, “similar” can be measured with geometry: the distance or angle between two vectors. Clustering, PCA, nearest neighbours and attention all depend on this.
Transformer linkThe first layer of every language model is exactly the Text mode here: token → id → embedding vector. The embedding table is a big learned matrix with one row per vocabulary word, often 50,000 rows × 4,096 numbers.

04The real goal: generalisation (under- and over-fitting)

Remembering the training examples is easy; a lookup table can do it. The real goal is to do well on new examples the model has never seen. This is called generalisation. To measure it we keep some data back as a test set.

On the right, the true relationship is the dashed curve. We see only a few noisy samples of it (blue dots), and we fit a polynomial of degree \(d\):

$$\hat y = w_0 + w_1x + w_2x^2+\dots+w_dx^d$$
  • Underfitting (degree 0–2): the model is too simple, so both training and test error are high.
  • Good fit (around 3–5): it captures the pattern but not the noise.
  • Overfitting (high degree, few points): the curve passes through every blue dot (training error ≈ 0) but swings wildly between them, so test error (orange) explodes.

Experiment: set the degree to 12, then raise the number of training points. More data tames a big model. This is the main reason modern models are trained on so much data.

Bias–variance in one sentenceA model that is too simple is biased and wrong in the same way on every dataset. A model that is too flexible has high variance: it changes a lot with every new random sample. Press “New sample” at degree 12 to see the variance.
Transformer linkLLMs have billions of parameters, enough to memorise their training data, yet they generalise because they are trained on trillions of tokens. Engineers watch the validation loss curve, exactly like the orange curve here, to decide when to stop training.

05Train / validation / test, and the workflow

Data is split into three parts. A good way to remember them is a student preparing for an exam:

SplitAnalogyUsed for
trainhomeworklearning the parameters \(\theta\) (weights)
validationmock examchoosing hyper-parameters: degree, learning rate, model size, when to stop
testfinal examone honest estimate of real-world performance, used once at the end

Parameters vs. hyper-parameters. Parameters are learned by the optimizer (the \(w\)’s). Hyper-parameters are chosen by you before training (the degree \(d\), the learning rate \(\eta\), the number of layers).

If you tune your choices on the test set, it quietly turns into training data, and your reported score becomes too optimistic. This is called data leakage.

06Four ways to learn: the paradigms

Learning methods are grouped by what kind of feedback the learner gets. Each one has its own lesson in this course:

SupervisedEvery example comes with the correct answer \(y\). Learn \(x\mapsto y\).
lesson →
UnsupervisedNo answers. Find structure such as groups or directions. Learn about \(p(x)\).
lesson →
Self-supervisedHide part of the data and predict it. The data supplies its own labels.
lesson →
ReinforcementNo answers, only a reward after acting. Learn by trial and error.
lesson →

Separately from the paradigm, we choose a model family: linear models, trees, neural networks, CNNs for images, RNNs and Transformers for sequences. Any family can be trained under any paradigm.

Transformer linkA chatbot like ChatGPT or Claude uses three paradigms in turn: (1) self-supervised pre-training on internet text (predict the next token); (2) supervised fine-tuning on written example answers; (3) reinforcement learning from human feedback (RLHF) to prefer helpful answers.
