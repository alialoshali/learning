Why it exists: supervised learning needs humans to label data, and that does not scale to the whole internet. Self-supervised learning hides part of each example and asks the model to predict it. The hidden part is the label, so every sentence, image or video becomes free training data. This is exactly how GPT, BERT and CLIP are pre-trained. It is the most direct step towards Transformers in the course.

01The trick: make the labels from the data

Take any raw input \(x\). Split it into a visible part and a hidden part, and train the model to predict the hidden part from the visible part:

$$x\;\longrightarrow\;(\underbrace{x_{\text{visible}}}_{\text{input}},\ \underbrace{x_{\text{hidden}}}_{\text{label}})\qquad \min_\theta\ -\log p_\theta\big(x_{\text{hidden}}\mid x_{\text{visible}}\big)$$

It is supervised learning in form, with an input, a target and cross-entropy, but unsupervised in cost: no human labels anything. Two main recipes for text:

Hidden partVisible partModel
Next-token (causal)the next wordall previous wordsGPT, Claude, Llama
Masked~15% random wordsall other words, both sidesBERT

Try it: type any sentence on the right and see how many training examples it produces automatically. One web page gives thousands; the internet gives trillions.

Transformer link“Pre-training” a large language model is simply this loop run on about 10¹³ tokens. Everything the model knows about grammar, facts and reasoning comes from trying to predict the hidden token.

02Next-token prediction: a tiny language model you can train

The simplest language model counts which word follows which in a corpus. This is an n-gram model. With one word of context (a bigram):

$$p(w_t\mid w_{t-1})=\frac{\text{count}(w_{t-1},w_t)}{\text{count}(w_{t-1})}$$

This is maximum-likelihood training: the counts are the parameters that minimise cross-entropy on the corpus. To generate text, repeat: look at the context, get the distribution, sample a word, append it.

Temperature \(T\) reshapes the distribution before sampling, \(p_i^{1/T}/\sum_j p_j^{1/T}\). \(T\to0\) always picks the most likely word (repetitive). Large \(T\) flattens it (chaotic).

Try it: edit the corpus, choose a context word, and look at the predicted next-word distribution. Press Generate. Then switch to 2 words of context: the text becomes more fluent, but most two-word contexts were never seen, so the model has no answer for them. Counting cannot generalise; a neural network can.

Transformer linkGPT does exactly this: context → probability of every next token → sample with temperature → append → repeat. The difference is that the count table is replaced by a Transformer, which generalises to contexts it has never seen and uses thousands of tokens of context instead of 1 or 2.

03Masked modelling: fill in the blanks (text and images)

BERT (2018) hides about 15% of the tokens and predicts them using context from both sides:

$$\mathcal L=-\sum_{i\in\mathcal M}\log p_\theta\big(x_i\mid x_{\setminus\mathcal M}\big)$$\(\mathcal M\) = set of masked positions; \(x_{\setminus\mathcal M}\) = everything that is not masked.

Seeing both sides makes BERT good at understanding (search, classification). But it cannot generate text left to right, which is why chatbots use the next-token objective.

Images work the same way. A Masked Autoencoder (MAE, 2021) cuts an image into patches, hides up to 75% of them and reconstructs the missing pixels. Images are very redundant, so a high mask ratio is needed to make the task hard enough to teach anything.

Try it: raise the mask ratio, then press Fill in. Our “model” here is only blurring in from neighbouring patches, so it can recover smooth regions such as sky but not objects. A trained network learns what objects look like and fills them in properly. That knowledge is what pre-training gives.

Transformer linkMAE is a Vision Transformer: each patch becomes a token, exactly like a word. Masking patches = masking tokens. The same architecture and the same objective work for both text and images.

04Contrastive learning: pull matching pairs together

Instead of predicting raw pixels or words, contrastive methods learn embeddings in which two views of the same thing are close and different things are far apart. CLIP (2021) uses 400 million (image, caption) pairs from the web; SimCLR uses two random crops of the same photo.

For a batch of \(N\) pairs \((u_i, v_i)\), compute every similarity \(s_{ij}=\cos(u_i,v_j)/\tau\) and train each image to pick its own caption among all \(N\):

$$\mathcal L=-\frac1N\sum_{i=1}^{N}\log\frac{e^{s_{ii}}}{\sum_{j=1}^{N}e^{s_{ij}}}$$This is the InfoNCE loss. It is just softmax + cross-entropy where the “correct class” is the matching pair.

Try it: drag the training slider. The pairs on the circle rotate towards each other, the similarity matrix becomes diagonal, and the loss falls. Lower the temperature \(\tau\): the softmax becomes sharper and the loss punishes near-misses more.

Transformer linkLook at the matrix: rows = queries, columns = keys, cell = scaled dot product, softmax per row. That is an attention matrix. CLIP’s image and text encoders are both Transformers, and the text encoder of image generators (like Stable Diffusion) comes from CLIP.

05Why it works: pre-train once, fine-tune with few labels

The pretext task (next token, masked patch, matching pair) is not the goal itself. It forces the model to build a representation \(h=\text{enc}_\theta(x)\) in which useful facts are easy to read off. Later, a small labelled dataset is enough:

$$\text{1. pre-train:}\ \ \theta\leftarrow\text{self-supervised on }10^{12}\text{ tokens}$$$$\text{2. probe:}\ \ \hat y=\sigma\big(w^\top \text{enc}_\theta(x)\big),\ \text{learn only }w$$

This last step is called a linear probe. On the right, two classes form rings, which no straight line can separate in the raw features. In a “pre-trained” representation (here: distance from the centre, the kind of factor a good encoder discovers), the same logistic regression separates them with just a handful of labels.

Try it: lower the number of labelled examples. Raw features fail at any size; the good representation works with only 4–6 labels.

Transformer linkThis is the whole LLM workflow: (1) self-supervised pre-training builds the representation; (2) supervised fine-tuning on a few thousand examples teaches the format; (3) RLHF polishes behaviour. Prompting (“few-shot learning”) is the extreme case: zero gradient steps, just examples in the context.

Teach it in one sentence: self-supervised learning creates its own labels by hiding part of each example and predicting it, which turns unlimited raw data into supervised training data. Next-token prediction on internet text is how every modern LLM learns.
