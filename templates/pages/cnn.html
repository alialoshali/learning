imagesconvolution · kernelsweight sharingpooling · receptive field→ Vision Transformers

Why it exists: an image is a huge grid of numbers, and what matters in it (an edge, an eye, a wheel) can appear anywhere. A plain neural network would need a separate weight for every pixel of every pattern at every position. A CNN slides one small learned filter across the whole image: the same weights at every position. This needs far fewer parameters, works wherever the object is, and builds features in layers from edges to objects. CNNs drove computer vision from 2012 to 2020, and the Vision Transformer is the idea that replaced them.

01Why not a plain MLP on pixels?

Flatten an image into a vector and feed it to an MLP. Two problems appear immediately:

  1. Too many parameters. A 224×224 colour image has 150,528 inputs. One fully connected layer with 1,000 neurons already needs 150 million weights.
  2. No sense of position. Shift the digit a few pixels and the flattened vector changes almost completely. The MLP has to learn “7 at the top-left”, “7 at the centre” and so on as separate patterns.

Try it: move the shift slider. The cosine similarity between the original and shifted pixel vectors drops quickly, even though a person sees the same digit. Then compare the parameter counts below the image.

CNNs fix both problems with two assumptions about images: locality (nearby pixels matter together, so each neuron looks at a small patch) and translation equivariance (a pattern means the same thing anywhere, so the same weights are used everywhere).

Transformer linkTransformers drop these built-in assumptions and learn what to look at with attention. That is why Vision Transformers need more training data than CNNs, but scale better once they have it.

02The convolution operation

A kernel (filter) is a small grid of weights, e.g. 3×3. Slide it over the image. At each position, multiply the kernel with the patch under it element by element, add everything up, and write the result into the output feature map:

$$Y[i,j]=\sum_{m=0}^{k-1}\sum_{n=0}^{k-1}X[i+m,\,j+n]\;K[m,n]\;+\;b$$

Each output value is a dot product between the kernel and one patch, so it is large when the patch looks like the kernel. A kernel is a pattern detector, and the feature map shows where the pattern occurs.

Try it:

  • Hover over an output cell to see its 3×3 window and the full multiply-and-add.
  • Pick vertical edge: the output lights up only where brightness changes from left to right.
  • Paint on the input grid, or click kernel cells to edit them (left click +1, right click −1).
Learned, not designedEdge, blur and sharpen kernels were designed by hand for decades. In a CNN, kernel values are parameters learned by backpropagation, just like the weights of an MLP. Trained first-layer kernels usually turn out to be edge and colour detectors anyway.

03Stride, padding and output size

Three settings decide the size of the output:

kernel size \(k\)size of the window (3, 5, 7…)
padding \(p\)zeros added around the border, so edge pixels get processed and the size can stay the same
stride \(s\)step between window positions. \(s=2\) halves the output size (downsampling)
$$n_{\text{out}}=\Big\lfloor\frac{n_{\text{in}}+2p-k}{s}\Big\rfloor+1$$

Common recipe: \(k=3,\ p=1,\ s=1\) keeps the size (“same” padding); \(s=2\) halves it.

Try it: change the settings and press Animate to watch the window slide. Grey cells are padding. Each output cell (right) corresponds to one window position.

Transformer linkA Vision Transformer’s first step is a convolution with kernel = stride = patch size (e.g. 16): non-overlapping windows that each become one token. Set \(k=s\) here to see the same thing.

04Feature maps on a real image, and channels

Applied to a whole picture, each kernel produces one feature map. A convolution layer has many kernels (e.g. 64), each producing its own map, so the output has 64 channels.

Colour images already have 3 input channels (R, G, B), so each kernel is really a 3-D block \(k\times k\times C_{\text{in}}\), and its output sums over all input channels:

$$Y_c[i,j]=\mathrm{ReLU}\Big(b_c+\sum_{c'=1}^{C_{\text{in}}}\sum_{m,n}X_{c'}[i+m,j+n]\,K_{c,c'}[m,n]\Big)$$Parameters per layer: \(C_{\text{out}}\cdot(k\cdot k\cdot C_{\text{in}}+1)\), independent of image size.

Try it: switch kernels to see what each one “sees” in the scene. Tick ReLU: negative responses are set to 0, so only matches of the pattern remain (orange = negative, blue = positive).

Transformer linkMultiple kernels looking for different patterns in parallel is the same design idea as multi-head attention: several heads, each with its own weights, looking for different relationships, with their outputs combined.

05Pooling and a complete CNN

Max pooling shrinks a feature map by keeping only the largest value in each 2×2 block. It halves width and height, keeps the strongest responses, and makes the network less sensitive to small shifts. (Modern nets often use stride-2 convolutions instead.)

$$Y[i,j]=\max_{0\le m,n<2}X[2i+m,\,2j+n]$$

A classic CNN repeats conv → ReLU → pool a few times. The maps get smaller in space but deeper in channels. Then it flattens and finishes with an MLP and softmax. Click the stages of LeNet-5 (1998, handwritten digits) on the right to see shapes and parameter counts.

Training is exactly as before: cross-entropy loss, backpropagation and SGD/Adam. Because a kernel is reused at every position, its gradient is the sum of the gradients from all positions. Data augmentation (random crops, flips, colour jitter) creates more training examples for free.

06Receptive field: from edges to objects

One neuron in layer 1 sees a 3×3 patch. A neuron in layer 2 sees 3×3 neurons of layer 1, which together cover 5×5 pixels. Every layer widens the receptive field, and pooling or stride widens it faster:

$$r_l=r_{l-1}+(k_l-1)\cdot j_{l-1},\qquad j_l=j_{l-1}\cdot s_l$$\(r\) = receptive field in pixels, \(j\) = distance between neighbouring neurons measured in input pixels (“jump”), \(s\) = stride.

This produces a hierarchy of features: early layers see small patches and detect edges and colours; middle layers combine them into textures and parts (eyes, wheels); deep layers see most of the image and respond to whole objects.

Try it: add layers and switch on stride 2 to see how quickly the highlighted area covers the image.

Transformer linkIn a Transformer, every token can see every other token from layer 1 on: the receptive field is global immediately. A CNN needs many layers to connect distant pixels; attention does it in one step. That is the key architectural difference.

07From CNNs to Vision Transformers

The Vision Transformer (ViT, 2020) treats an image like a sentence:

  1. Cut the image into \(P\times P\) patches (e.g. 16×16 pixels).
  2. Flatten each patch and project it with one shared linear layer to a vector, a patch token. This is a convolution with kernel = stride = \(P\).
  3. Add position embeddings and feed the sequence of tokens to a standard Transformer.
$$\text{tokens}=\frac{H}{P}\cdot\frac{W}{P}\qquad\text{e.g. }224/16=14\ \Rightarrow\ 196\text{ tokens}$$
