1. The idea: fit a line

Problem. Imagine you have a bunch of data points—say, the square footage of different houses and their sale prices. If you plot them on a graph. We have pairs (x, y), for example house size and price. We want a rule that predicts y for a new x.

Model. The goal of linear regression is to find a single straight line that minimizes the total distance between itself and all those scattered data points. The algorithm looks at the errors (the vertical distance from each point to the line, called "residuals") and adjusts the line until the sum of those squared errors is as small as possible.

ŷ = w·x + b
Model: the prediction is the slope-weighted input plus an intercept.
ŷ = predicted output
w = slope / weight
x = input feature
b = intercept / bias
Where it came from: the straight-line model used in linear regression; in the lesson it is also the scalar form of a single nn.Linear layer.

Residual. For each point, the vertical gap between the prediction ŷ and the truth y is the error eᵢ = ŷᵢ − yᵢ. The red segments in the plot are residuals.

Try it: drag w and b and watch the MSE. Then press "Best fit". Turn on "squares" to see why big misses hurt so much.

Transformer link ŷ = w·x + b is exactly one nn.Linear layer with a single input and output. A transformer is mostly huge stacks of linear layers (Q, K, V projections and the feed-forward block), just with vectors and matrices instead of single numbers.

2. The loss: one number for "how wrong"

To learn, the machine needs a single score of how bad the current line is. We average the squared residuals: the Mean Squared Error.

L(w,b) = 1/N · Σᵢ (w·xᵢ + b − yᵢ)²
Loss: square each prediction error and average those squared errors over all N examples.
L(w,b) = loss for the current parameters
N = number of training examples
Σᵢ = add over every example i
xᵢ = input of example i
yᵢ = true output of example i
w·xᵢ+b = prediction ŷᵢ
² = square the residual
Where it came from: this is the Mean Squared Error definition applied to the linear model ŷᵢ = w·xᵢ+b.

Why squared? (1) errors never cancel, (2) big misses are punished more, (3) it is smooth, so we can differentiate it.

Fix b and vary only w: the loss forms a bowl (a parabola). Linear regression has exactly one bottom and no traps. The dot on the right follows the w slider from section 1. Move it to the bottom of the bowl.

Transformer link Training is always "define a loss, make it small". Language models use cross-entropy (how surprised the model is by the true next token) instead of MSE, but the loop is identical. Real loss surfaces are not clean bowls, but we still walk downhill on them.

3. Learning: gradient descent

Instead of guessing, use calculus. The gradient tells us which way the loss rises fastest; we step the opposite way.

∂L/∂w = (2/N) Σᵢ (ŷᵢ − yᵢ)·xᵢ
∂L/∂b = (2/N) Σᵢ (ŷᵢ − yᵢ)
Gradient: these derivatives tell us how the loss changes when we change the slope w or bias b.
∂L/∂w = slope of the loss with respect to w
∂L/∂b = slope of the loss with respect to b
ŷᵢ−yᵢ = residual for example i
2/N = derivative of the square + averaging factor
Where it came from: differentiate the MSE formula above with respect to w and b using the chain rule.
w ← w − η·∂L/∂w
b ← b − η·∂L/∂b
Update: move each parameter in the direction that lowers the loss.
η = learning rate / step size
← = replace the old value with the new value
− = move opposite the gradient
Where it came from: the standard gradient-descent rule θ ← θ − η∇L, written separately for w and b.

η (eta) is the learning rate, the step size. The training loop is: predict → compute loss → compute gradient → update → repeat.

Experiment: (1) η = 0.01, press "×50": smooth descent. (2) η = 0.001: painfully slow. (3) η = 0.04: the loss explodes, because steps overshoot the bowl. The graph is MSE by default; you can switch on log₁₀ display only when the range becomes too large to see comfortably.

Transformer link This is precisely how transformers train, with three upgrades: gradients come from backpropagation (the chain rule applied automatically), updates use Adam (gradient descent with momentum and per-parameter step sizes), and data arrives in mini-batches. Learning-rate tuning and warmup schedules exist because of the explosion you just saw.

4 Concrete example: use flat size + age to predict price

Question. Suppose we want to estimate the sale price of a flat. We know two things about each flat:

  • Size in square metres (m²).
  • Age in years.

We use both features at the same time. A simple linear model says:

Pricê = wsize·Size + wage·Age + b
Idea: start with a base price, add an amount for every square metre, and subtract an amount for every year of age.
Pricê = predicted price
Size = flat area in m²
Age = flat age in years
wsize = price change per m²
wage = price change per year
b = base/intercept price
Where it came from: this is the same linear model ŷ = w·x + b, extended from one input feature to two input features.
Read the signs carefully A positive wsize means a larger flat increases the prediction. A negative wage means an older flat decreases the prediction, all else equal.

5. Many features, and the bridge to transformers

Real inputs have many features (size, rooms, age…). Stack them into a vector x and the weights into a vector w; for a whole dataset, use a matrix X (one row per example).

ŷ = X·w + b
Y = X·W + b
Vector/matrix form: the same linear idea works when an input contains many features or the model has many outputs.
X = data matrix (rows = examples)
w = vector of feature weights
W = matrix of weights for many outputs
Y / ŷ = target / predicted outputs
b = bias term(s)
Where it came from: matrix notation for the same linear model; the scalar equation is recovered when there is one input feature and one output.

For linear regression only, the minimum has a closed form, the normal equation. Gradient descent is used anyway because it scales to models where no closed form exists.

w* = (XᵀX)⁻¹ Xᵀy
Normal equation: for ordinary linear regression, this gives the least-squares solution directly instead of iterating with gradient descent.
w* = optimal weight vector
Xᵀ = transpose of X
(XᵀX)⁻¹ = inverse of XᵀX, when it exists
y = vector of target values
Where it came from: solving the least-squares objective analytically by setting its gradient with respect to w to zero.

Practical rule: scale features to similar ranges (e.g. mean 0, std 1). If one feature is 1000× larger, its bowl direction is steep and the learning rate must shrink for everything, so training crawls. Transformers get the same benefit from LayerNorm.

Why nonlinearity matters Stack two linear layers and you get another linear layer: W₂(W₁x) = (W₂W₁)x. Without activation functions, a deep network is secretly just linear regression. Attention's softmax and the feed-forward activation are what give transformers their power.
Recap to teach 1) Model: ŷ = w·x + b. 2) Loss: MSE measures error. 3) Gradient descent: nudge parameters against the gradient. 4) A transformer repeats this same loop with far more parameters, a different loss, and nonlinearities.
